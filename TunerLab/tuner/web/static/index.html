SCPI 调试工具

          
连接报 -113 Undefined header 或换用新仪器时，点「运行 SCPI 探测」一次性读出 *IDN?（型号/固件）、本机支持的测量定义写法和取数/功率/触发命令。探测只发查询与无害配置，会临时创建 TL_probe_* 测量，请先断开连接（GPIB 资源不能被两个会话同时打开）。桌面端「系统 → SCPI 调试工具」页功能更完整。

          

            
            
            
            
          

          
尚未运行探测。

        

        
支持两种接口：TCP/IP（SCPI，默认端口 5025，无需 VISA 运行时）；GPIB（VISA 资源名，如 GPIB0::17::INSTR，Agilent/Keysight 82357B USB-GPIB 卡需安装 Keysight IO Libraries Suite，可用「检测 VISA」读取实际资源）。两种接口共用同一套厂商 SCPI 预设：罗德(R&S)、Keysight E5071C(ENA)、Keysight N5247 PNA-X、思仪(AV3672)、安立(VectorStar/ShockLine)。TCP/IP 连不上请确认：① 网段互通、② 仪器已开启 SCPI 且允许 LAN 控制、③ 防火墙放行 5025；GPIB 连不上请确认：① VISA 运行时已安装、② 82357B 在 Connection Expert 中可见、③ GPIB 主地址正确。
