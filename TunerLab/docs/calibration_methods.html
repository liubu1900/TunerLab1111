0. 结论速览

直接回答你的问题：TunerLab 目前校准参数（调谐器表征）的采集方式只有 1 种——指定每个轴的机械点位，逐点移动 + 逐点实测 （笛卡尔网格）。所谓"按史密斯图自动确认点位"目前不是采集方式，而是基于已采集网格的查表/插值推断， 且代码里明确标注为 predicted=True（预测值，非实测）。
层次TunerLab 现状方法数与行业通用方法的关系

还有一个必须知道的现状：校准工作台的运动侧目前仍是 Mock （studio_init_hardware 里 motion = MotionController(config)，即 Mock 控制器）。 真实 Zmotion 四轴目前只接在"运动控制台"页面，与校准工作台尚未打通； 只有矢网侧可以切到实机（vna_source=real）。

1. TunerLab 现状：三条路径

1.1 路径 A — 采集/表征（唯一的一种）

环节实现位置做法

这是与行业通用方法最大的结构性差异：主流方案都是在 Smith 图上均匀铺点（点数与维度无关地线性增长）， 而当前实现是在机械坐标立方体上铺点（点数随探针数幂次增长），且大量点位落在 Smith 图的"死区"（Γ 很小）， 对覆盖同样的阻抗范围是浪费。

1.2 路径 B — 点位自动确认（查表 + 插值，均为推断）

方法实现数学注意
(b1) Γ 平面最近邻查表search.py::GammaSearchEngine.search() 在 (Re Γ, Im Γ) 上建 cKDTree，取最近 k 点， 误差 = 复平面欧氏距离 只给出已标定过的点位；误差可判"可达/不可达"
(b2) 凸包插值 + 局部优化optimize_local() LinearNDInterpolator（Delaunay 凸包）在归一化机械坐标上插值， SLSQP 最小化 |Γ(x) − Γ_target|² 返回 predicted=True；凸包退化（QHullError）时显式回退到最近邻
(b3) 多频加权寻优search_multi() 多频 Γ 误差的加权 RMS，排序取前 k 用于非谐波相关多频场景的雏形
关键区别：这是"先标定、再查表"的离线推断， 不是行业通用方案那种"给目标 → 自动移动 → 实测 → 迭代收敛"的闭环自动寻点。 当前代码没有任何"根据实测结果反馈调整点位"的迭代回路。

1.3 路径 C — 验证

方法实现口径
(c1) 矢量复现性validation.py::repeatability_report() A/B 两点交替往返 ≥3 次，按频率统计复数平面的 矢量 RMS / 样本标准差 / 最大偏差 （线性单位，不是 dB 差），并保留完整 S11/S21 谱
(c2) 标定点位复核web/handlers.py::studio_validate 对 valid 点位重新实测并与库内数据比对

2. 商用调谐软件支持的方法

行业通用的方法学核心（专利摘要原文要点）：单/多探针高频 slide-screw 调谐器采用快速校准算法， 在 Smith 图上创建分布均匀的校准点，并用二阶插值算法在校准点之间取值； 快速调谐算法 = 先做一般搜索（general search）找到最近的校准点， 再用细插值网格做梯度搜索（gradient search）逼近目标。 专利称可达 −60 dB 调谐精度（Smith 图上偏差 0.001）， 而没有细网格插值时仅约 −20 dB（偏差 0.1）。 该方法同样适用于双探针/三探针谐波调谐器。
行业通用的能力具体做法出处
① Smith 图均匀布点 每个频率在尽量等间距覆盖整个 Smith 图的固定数量阻抗点上标定；点数可选 95 / 181 / 361（可选 385）；系统软件提供 181 点。 181 点并非"只能调 181 点"——可调状态数达 50 万 ~ 1100 万 通用应用笔记摘录
② 二阶插值（相干 X/Y 方向） 在相位/幅度近似解耦的坐标系里插值：水平(X)控制相位、竖直(Y)控制 |Γ|。 取最近 3 个水平层 × 最近 3 个竖直层 = 9 个校准点网格， 先在竖直方向用二阶 Lagrange插值生成虚拟点，再在水平方向插值 通用应用笔记摘录
③ 两段式快速调谐 一般搜索（定位最近校准点）→ 梯度搜索（细插值网格）→ 目标 通用专利方法（阻抗调谐器标定与调谐）
④ 校准类型体系 区分 VNA 校准（推荐 TRL；SOLT 在 3–4 GHz 以上不可接受）、 Setup 校准（所有组件二端口存 .S2P）、Fixture 校准（自研 TRL，可含 1/4 波长变换器与偏置网络）、 Wafer Probe 校准、In-situ 调谐器校准（不拆机同时表征 f0/2f0/3f0）、 8-term 校准（用于 HAILP 有源/无源混合谐波负载拉取） 通用资料：Calibration 页
⑤ 快速预匹配调谐器表征 400×400 = 160,000 个阻抗点/频率，新型表征算法把耗时压到 ≤20 分钟/频率， 配合插值实现"等效连续可调" 厂商产品简介 PN-52
⑥ 调谐范围（Γ 口径） 标准 CCMT/MTS 可调 Γ = 0.82~0.85（VSWR 10:1~12.5:1）； -HR 选件到 Γ = 0.904（VSWR 20:1）；更低内阻需配 λ/4 变换网络 厂商产品简介 PN-24
图 2  通用方法：均匀布点 → 二阶插值 → 一般搜索 → 梯度搜索

3.行业通用的表征方法

行业通用方法学核心：用户只需声明测量应用 （Load/Source Pull 还是 DVT 设计验证测试）， 软件就自动选择最合适的调谐器表征方法与条件； 表征参数里直接暴露阻抗点密度（Low / Medium / High）与 点间距指标（Magnitude / Max Phase Step），并可在 Smith 图上可视化布点。 DVT 表征比常规表征快 10~100 倍（取决于所选频率数）。
行业通用能力具体做法出处
① 两种表征方法自动选择 Source/Load Pull：单/多 carriage 调谐器，在被表征频率上做阻抗调谐，适合负载拉取； DVT：单 carriage 调谐器，适合器件验证测试，启用频率插值。 软件按应用自动选方法与条件 商用表征软件 MAPCON 2024；R&S 负载拉取基础讲义
② 点密度与布点可视化 表征参数：阻抗点密度 Low / Medium / High、 Point Separation Magnitude 0.07、Max Phase Step 15； 点击 Visualize 把布点显示在 Smith 图上 商用软件界面（R&S 讲义截图）
③ 预标定 LUT 预标定 = 在各 X/Y 位置用已校准的 VNA记录探针 S 参数， X/Y 的选取使阻抗在 Smith 图上尽量均匀分布； 点数用户可定义（通常 300~3000） 自动调谐器数据表（2.4 mm / 1.85 mm）
④ 二维插值扩展可调空间 目标阻抗落在标定点之间时，用二维插值算法求新的物理 X/Y 位置； 插值把可调阻抗数远超初始标定范围；标定表足够密时， 复现性（回到标定点）与精度（插值）表现相当 自动调谐器数据表（2.4 mm / 1.85 mm）
⑤ 验证闭环 命令调谐器到一组插值得到的阻抗，用已校准的 VNA测其 S 参数， 计算并报告误差矢量；若低于业界公认门限则建议重新标定 商用表征软件 MAPCON 2024
⑥ 频率维度能力 支持基波、谐波、非谐波相关多频、频率插值调谐； 增强的频率插值与更快的多频表征 商用软件特性表
⑦ 硬件端 LUT + 去嵌入 专利控制器（US 8,823,392）内置处理器与存储：标定后 LUT 写入 flash， 同时存入被动件（转接头/电缆/夹具/探针/衰减器）的 S 参数文件； 控制器据此计算所需探针位置，并对 tuner↔DUT 与 tuner↔仪器两侧做去嵌入， 还能处理非 50 Ω 终端 自动调谐器数据表
⑧ 开放指令接口 控制器支持 raw TCP/IP ASCII 直连指令（任意 socket 语言 / Telnet）： 直接阻抗调谐、参考面平移、VSWR 测试等 自动调谐器数据表
图 3 行业通用流程：声明应用 → 自动选方法 → 点密度与布点可视化 → 表征 LUT → 验证闭环

5. 差距清单与实现优先级

优先级项做什么对标
P0 把实机 Zmotion 接入校准链路 studio_init_hardware 用 ZmotionMotionController 替换 Mock，并复用运动控制台那套标度自检与急停逻辑 ——（自有阻塞项）
P0 Smith 图均匀布点生成器 新增 tuner/pointplan.py：以 Γ 均匀分布为目标生成轴坐标， 支持密度档位与布点可视化，取代笛卡尔积 均匀布点 + 密度分档
P1 二阶插值引擎 按经典 9 点网格 + 二阶 Lagrange（X=相位 / Y=幅度）实现 S 参数插值 通用插值算法
P1 两段式寻点 一般搜索（最近标定点）→ 梯度搜索（细插值网格）， 目标精度对齐 −60 dB / 0.001 口径 通用调谐算法
P1 验证闭环 插值点复测 → 误差矢量 → 门限判定 → 给出"建议重新标定"结论 行业通用验证闭环
P2 频率插值 在表征频率之间做 Γ/阻抗插值，支持非谐波相关多频 行业通用频率插值
P2 去嵌入与参考面 引入 .S2P 组件库，支持 Setup/Fixture 分层去嵌入与参考面平移 夹具校准 + 组件 .S2P 去嵌入
P2 谐波/多调谐器 基波 + 2fo/3fo 同时表征与多调谐器级联 两家的谐波调谐器支持
建议的落地顺序：先做 P0-2（Smith 图均匀布点）——它同时解决 "点数爆炸"和"Γ 死区浪费"两个问题，且不改数据结构（仍是 HDF5 的 positions + s）。 再做 P1-2（二阶插值） 与 P1-3（两段式寻点），把调谐精度从当前的"查表最近邻" 提升到 −60 dB 量级。

P1-1 / P1-2 已落地的内容：新增 tuner/interp.py， TensorInterpolator 逐轴做二阶 Lagrange（幅度轴先、相位轴后， 与通用次序一致；2 维即其 9 点邻域，n 维为 3ⁿ 点）， ScatteredInterpolator 对散点做局部二次加权最小二乘； 两者都插值四个 S 参数再换算 Γ。TunerResponseModel.tune() 实现一般搜索 → 梯度搜索 → 细网格三阶段并逐阶段报告误差矢量。 GammaSearchEngine 新增 response_model() 与 tune()；Web 阻抗调谐页可选算法与插值层级策略，并显示阶段误差表。
实测（Mock 调谐器，63 点网格）：最近邻查表 |ΔΓ| = 1.02e-01（约 −20 dB， 正是通用方法所述"无细网格插值"的水平）→ 梯度搜索后 1.54e-08，提升约 7 个数量级。
实测发现：插值精度主要受相邻层之间的相位跨度支配——网格加密一倍误差降到约 1/4 （二阶收敛）。软件据此给出 X 层数建议（recommended_phase_levels()： 360° 相位跨度、20° 步长上限 → 19 层），这是比换算法更有效的旋钮。

仍待补：无。P1-1 / P1-2 / P1-3 三项均已落地。

P1-3 已落地的内容：新增 tuner/tuner_validation.py， 按行业通用做法实现闭环：选插值点（张量网格取单元中心；散点取远离实测点的采样） → 实测（命令机器到该点、用已校准仪器测 S）→ 算误差矢量 （|ΔΓ|、幅度分量、相位分量，dB 等价量）→ 判定（超容差即建议重标定）。 报告还会指出哪一项占主导：幅度主导 → 标定点太稀/探针深度标度；相位主导 → X 相位层数不足。 Web「验证报告」页新增对应面板（点数/容差/策略 + 逐点结果表 + 判定结论）， 后端 POST /api/studio/validate_interpolation 在工作线程里跑并报告进度。
实测（Mock 调谐器，63 点网格、4 验证点）：最大 |ΔΓ| = 0.088140（−21.1 dB）， 判定「建议重新标定」，并指出幅度分量主导（0.0755 vs 相位 0.0033）→ 结论是标定点太稀， 而不是标度问题。这个闭环正是把"插值精度"从口号变成可测量指标的东西。

P0-1 已落地的内容：校准工作台的运动来源可切到实机 Zmotion， 复用「通讯设置」那条控制器连接（不二次打开控制器）；行程由操作者显式声明 （X/Z 起止与安全 Z），控制器出厂软限位 ±2e8 只作外层保护； 标度闸门强制要求每轴 feedback_scale ≈ 1 才允许初始化—— UNITS 差 84 倍时校准网格会让机器实际走 84 倍距离。 标度自检现在会给出修正后的 UNITS（当前 UNITS ÷ 实测比值）， 可一键写入控制器并保存设置（改写后该轴强制重新回零）。
