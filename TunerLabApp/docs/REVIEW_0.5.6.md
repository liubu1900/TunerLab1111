# TunerLab 0.5.6 项目检查与改进

检查日期：2026-11-09。范围：Windows 桌面主入口、共用后端、目录策略、后台任务、退出生命周期、内嵌 Web、测试与打包配置。

## 使用逻辑与架构

`python -m tunerlab_app` → `shell.main` 建立日志、单实例保护和主窗口。窗口持有一个 `TunerSession`；`SharedState` 将会话交给校准页面和内嵌 Web。设备页负责通讯、轴运动与参数；校准页通过 `handlers` / `studio_bridge` 调用模型、运动规划、矢网及 HDF5/SQLite 数据管理。

标准流程：选控制器模式与型号 → 连接 → 参数/回零/标度检查 → 配置矢网 → 五步建库向导 → 采集/续扫 → 打开有效校准库 → 搜索目标点位 → 移动并实测 → 验证和导出。连接控制器不等于可以开始实机校准；搜索到匹配点位也不等于 RF 实测通过。模拟运动和模拟 RF 的来源须分别确认。

现有设计优点：后端复用，桌面与 Web 共享状态；数据库支持续扫；实机测试显式 opt-in；虚拟模式及离屏测试允许无硬件开发；Windows onedir 打包保持 DLL 和静态资源目录结构。

## 已落实修正

| 问题 | 修正 |
|---|---|
| 硬编码 home/Documents 忽略 Windows 文档重定向 | 用 Windows Shell API 获取实际 Documents；新增 TUNERLAB_DATA_DIR 选取可写数据目录 |
| 同秒默认路径可能重复 | 文件名增加微秒和随机后缀，减少连续建库路径碰撞 |
| 后台任务依赖闭包接收 Qt 信号 | 使用 GUI 线程 QObject slot 和明确 queued connection；回调后释放任务引用 |
| 用户取消退出前就停止 Web | 先处理退出决定；取消退出保留服务 |
| 请求取消校准后立即断开控制器 | 保持窗口与连接，等待当前点协作退出后再次关闭，避免并发销毁 |
| 先探测并释放端口，再绑定 HTTP server | 直接绑定端口 0 并读取实际端口；停止时回收服务线程 |
| 发布校验仅比较大小及 EXE MD5 | 所有文件流式 SHA-256 校验；拒绝重复 ZIP 条目、损坏 ZIP、缺失资源及同长度内容变化 |
| 安装器 0.5.3 / 应用 0.5.5 元数据不一致 | 应用、Windows 文件版本、Inno Setup 统一为 0.5.6；加入一致性测试 |
| Linux 加载 Windows DLL 抛出 AttributeError | 改为明确平台错误；DLL 加载测试仅在 Windows 运行 |
| 缺少统一使用入口及构建自动化 | 根 README 梳理操作逻辑；Actions 配置跨平台测试、Windows EXE 构建、冒烟、ZIP 校验及仓库 artifact |

## 验证边界

在 Linux / Python 3.12 / requirements-tested.txt 固定直接依赖下执行后端、桌面和新增回归测试；离屏构建窗口并检查静态资源，执行本地 HTTP 请求。新增测试覆盖重定向路径、文件名、后台成功/异常回调线程、退出取消、Web 重启及同长度资源篡改。

Windows EXE 构建、安装器和真实控制器/矢网不能由 Linux 完成验收。新 Actions 工作流需在 GitHub 实际执行成功后才可认定 ZIP 已生成。没有关闭硬件授权门禁，也没有执行实际运动或修改现场设备参数。

## 后续优先改进

1. **机型配置（高）**：TunerSession 仍有特定机器反馈标度和回零模式自动修正；motion_adapter 绑定特定 OP/原点输入。应将型号、单位、输入输出、回零策略改为有版本的机型档案，经操作员确认后迁移。缺少现场资料时不修改物理约定。
2. **完整退出协调（高）**：本次处理 calibration_thread 的退出顺序；独立 VNA 扫描、点选调谐及全局线程池任务仍应统一注册与取消，避免关闭期间继续调用设备。
3. **连接异步化（中）**：菜单连接和自动连接仍有同步调用，应与通讯页后台操作统一，防止慢网络阻塞 UI。
4. **桌面/Web 操作互斥（中）**：共享会话不等于任务级互斥；应在后端统一状态机，明确采集、手动运动、调谐、断连和型号切换的允许转换。
5. **单实例竞争（中）**：当前探测并清理本地 socket 的策略需 Windows 双进程同时启动测试；应区分“已运行”和“无法取得锁”。
6. **交付完善（中）**：补充 Windows 现场回归、安装/卸载/升级、代码签名及长期保存发布包策略。Actions artifact 有保留期限，不能当永久交付存储。

未落实项是后续工作，本次修正不代表完整实机认证。运动参数、软限位、回零方向与联锁仍需按现场 SOP 验证。
