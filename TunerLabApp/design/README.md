# 「设备」四页 UI 方案（单文件版）

**唯一交付物：`tunerlab-device-ui.html`** —— 5 套方案、4 个页面、20 张 1600×980 实拍图，
全部以 base64 内嵌在这一个文件里，离线双击即可打开，不依赖任何外部图片或字体文件。

## 打开方式

直接双击 `tunerlab-device-ui.html`（或拖进 Edge / Chrome）。

顶部五个页签切换方案，点任意图片放大，Esc 关闭；右上「五方案横向对比」按页面把五套并排。

## 五套方案

| 方案 | 结构 | 优点 | 代价 |
|---|---|---|---|
| 1 浅色仪器面板 | 78 px 图标窄轨 + 顶部页签，硬边框、青绿状态色 | 贴近仪器操作习惯 | 边框偏多 |
| 2 浅色工程卡片 | 212 px 分组侧栏 + 白卡片 + 蓝色主色 | 分组清晰、最易落地 | 留白较多 |
| 3 双栏工作台 | 顶部页签 + 左参数栏 / 右工作区 | 屏幕利用率最高 | 页签层级浅 |
| 4 高密度 HMI | 170 px 树形导航 + 12 px 等宽 + 表格优先 | 1366×768 一屏看全 | 视觉朴素 |
| 5 仪表盘 | 图标轨 + KPI 卡片 + 大面积绘图 | 巡检/演示友好 | 参数密度最低 |

## 统一约定

- 字体：Noto Sans SC，300/400/500/600/700 五档字重（`tunerlab_app/fonts.py`）
- 底色：全部浅色
- 组件语义统一：卡片 / 表单行 / 工具栏 / 状态表 / 轴面板 / 迹线窗

## 生成脚本

| 脚本 | 作用 |
|---|---|
| `build.py` | 生成 5 个独立可交互原型 + 截图（`--shots`） |
| `single_file.py` | 拍齐 4 页 × 5 方案并内嵌成单文件（交付物） |

改动原型后依次运行：`python design/build.py --shots` → `python design/single_file.py`。
